# Support

## Where to ask

Email [info@getdefy.co](mailto:info@getdefy.co) when you need help with setup or usage. Use the repository's [issue chooser](https://github.com/getdefy-co/travel-rule/issues/new/choose) for reproducible bugs and scoped feature requests. Read [README](./README.md), [Architecture](./ARCHITECTURE.md), and [Troubleshooting](./docs/troubleshooting.md) first.

Do not send passwords, tokens, private keys, personal data, database dumps, or vulnerability evidence to the general support address.

Security vulnerabilities and reports containing sensitive evidence must never use an issue. During the private pre-release phase, only authorized collaborators can use a maintainer-approved private repository channel to which they already have access; external intake is not yet available. Maintainers must enable and verify the future [GitHub private vulnerability report form](https://github.com/getdefy-co/travel-rule/security/advisories/new) before public visibility. See [Security Policy](./SECURITY.md).

## Information to include

- Commit SHA and whether the repository is unmodified
- Ubuntu, Docker Engine, Compose, Node.js, and npm versions
- Exact command and sanitized output
- Relevant service health and bounded logs
- Minimal reproduction with synthetic data
- Checks already run and their observed outcomes

Never include secrets, JWTs, API keys, passwords, private keys, database dumps, personal data, full request bodies/query values, Travel Addresses, or protocol token URLs.

## Support boundaries

This community project provides no guaranteed response time, uptime, compatibility, in-place upgrade execution, legal/compliance advice, managed deployment, certificate authority, peer onboarding, incident response, or production support. Operators remain responsible for regulatory interpretation, VASP identity, PKI/trust, backups, monitoring, network controls, data retention, and change approval.

The public-release gate for `ivms101@2.0.0` remains unresolved. Support discussions must not treat the repository or its container images as approved for public redistribution.
